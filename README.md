# Weather App 🌦️

A real-time weather application with dynamic weather backgrounds, forecasts, rain animations, and responsive UI.

## 🚀 Live Demo

👉 [View Live Weather App](https://weather-il973ieiy-shaikhidrishs-projects.vercel.app)

## 🛠️ Technologies Used

- React.js
- Vite
- Node.js
- Express.js
- OpenWeather API
- Vercel
- Render

## 📂 Project Structure

- `frontend/` – React frontend
- `backend/` – Express.js backend
